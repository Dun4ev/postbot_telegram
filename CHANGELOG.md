# Changelog

## [2.1.0] - 2026-03-01
### Added
- Локальное хранение медиафайлов в папке `storage/`.
- Скрипт `importer.py` для переноса данных из экспортов Telegram.
- Таблица `assets` для ведения постоянной библиотеки контента.
- Команда `/now` для мгновенной публикации.
- Автоматическое создание меню команд в Telegram.
- Файл `.env.example` для упрощения настройки новых каналов.

### Changed
- `bot.py`: теперь использует локальные пути к файлам вместо `file_id`.
- `x_publisher.py`: загрузка в X происходит напрямую с диска.
- `docker-compose.yml`: добавлен volume для персистентного хранения медиа.

## [2.0.0] - 2026-03-01
### Added
- Интеграция с X.com (Twitter).
- Поддержка альбомов (фото/видео).
- Автоматическое сокращение текста до 280 символов для X.

## [1.0.0] - 2024
### Added
- Базовая логика очереди и публикации в Telegram.
